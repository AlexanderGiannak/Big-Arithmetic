Ever wondered what 2^100,000 or 999! (factorial) is?
Normal languages are limited to 64 or slightly higher bit numbers. However this simulator instead goes back to elementary school days and re-impements all arithmetic operations we noramlly take for granted. 

All 'integers' are actually converted to strings internally, which allows to operate on unbounded lengths. 
Optimization was not prioritzed in this demo to a large extent, but multiply for instance uses Karastuba mulitplication instead of the slow naive approach.
